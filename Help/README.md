# Generated help entries for s2n-bignum tactics

Each `<TACTIC>.hlp` file describes one s2n-bignum tactic, laid out like the
entries in HOL Light's `Help/` directory.

The files are placed by where the tactic is defined:

- `Help/` holds the tactics defined under `common/`, which the x86 and ARM
  proofs share.
- `Help/x86/` holds the tactics defined under `x86/`, including the
  `LOCAL_..._TAC` helpers that individual proof files define.
- `Help/arm/` will hold the tactics defined under `arm/`.

Many names, for example `DISCARD_FLAGS_TAC` and most `LOCAL_..._TAC` helpers,
are defined separately for x86 and ARM with different code. Their x86 and ARM
entries will have the same file name in different folders.

The entries were generated by an LLM from tactic traces: the goal before and
after each application of a tactic, recorded while running s2n-bignum's x86
proofs at commit 7948ca1. This includes the entries in `Help/`, so they
describe the shared tactics as the x86 proofs use them. A second LLM call
rewrote each generated description into this layout, and a third call checked
that the rewrite neither adds nor drops a statement. Entries that failed this
check are not included.

Statements such as "in the observed traces" describe what the recorded traces
show, which may not cover every use of the tactic.

The entries have not yet been reviewed by a person. More tactics, including
those of the ARM proofs, will be added. Feedback is welcome in
https://github.com/awslabs/s2n-bignum/issues/496 and
https://github.com/awslabs/s2n-bignum/issues/501.
