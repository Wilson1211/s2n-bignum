# Generated help entries for s2n-bignum tactics

Each `<TACTIC>.hlp` file in this directory describes one s2n-bignum tactic,
laid out like the entries in HOL Light's `Help/` directory.

The entries were generated by an LLM from tactic traces: the goal before and
after each application of a tactic, recorded while running s2n-bignum's x86
proofs at commit 7948ca1. A second LLM call rewrote each generated description
into this layout, and a third call checked that the rewrite neither adds nor
drops a statement. Entries that failed this check are not included.

Statements such as "in the observed traces" describe what the recorded traces
show, which may not cover every use of the tactic.

The entries have not yet been reviewed by a person. More tactics, including
those of the arm proofs, will be added. Feedback is welcome in
https://github.com/awslabs/s2n-bignum/issues/496 and
https://github.com/awslabs/s2n-bignum/issues/501.
